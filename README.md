## `01` &nbsp; About me

Olá! Sou **Maria Eduarda Nogueira**, estudante de programação com interesse em desenvolvimento de software e criação de aplicações web.

Tenho conhecimentos em **HTML, CSS e JavaScript**, explorando a construção de interfaces, a organização de páginas e a implementação de funcionalidades.

Também estudo **Java**, buscando fortalecer meus fundamentos de programação e orientação a objetos.

Utilizo **Git e GitHub** para versionar meus projetos, organizar meu aprendizado e acompanhar minha evolução.

> Creativity makes it different. Code makes it possible.
